无时间/随机输入，无本任务持久化行为或错误通道。

| 场景 | 验收行为 |
| --- | --- |
| reserve_leader | 前规则 voter 从 peer1 回溯到 peer2，为后续 leader 留出 peer1 |
| reserve_follower | follower 后缀与前规则平局处理 |
| priority_leader_first | 保留输入规则优先次序 |
| orphan_order | 多余 peer 按健康/ID 顺序保留 |
| shortage | 前规则数量优先，后规则可为空 |
| role_conversion | learner 与 voter 选择、角色转换子集 |
| health_order | 健康优先、pending 次之、down 成为 orphan |
| witness_on / witness_off | witness 排除 leader 与角色不匹配 |
| missing_store | 未知 store 的 peer 保留为 orphan |
| later_isolation | 前规则平局后继续优化后规则隔离，选择 [2]/[1,3] |
| first_isolation | 前规则隔离优先，确定性平局保留 [1,2]/[3] |
| isolation_priority / constraint_priority | 调换规则顺序会改变隔离与约束冲突时的最优解 |
| constraint_backtrack | 通用 voter 回溯，为 zone=a 的后规则留出 peer1 |
