# PD Rust 存储选主计划

## Go 只读硬约束

- Go 仅供只读参考。禁止新增、修改、删除、重命名任何 `.go` 文件（含生产代码、测试、oracle、生成文件及临时目录中的 Go 工具）；`go.mod`、`go.sum`、`go.work`、`go.work.sum` 同样只读。所有新增实现与测试使用 Rust，必要的非 Go 验证脚本和证据文档须在任务范围内。
- 禁止通过生成器、格式化、依赖整理、failpoint 注入或构建脚本间接改写 Go；不得运行会改写 Go 的 make 测试入口、failpoint 启停命令、`go generate`、`go mod tidy` 或 Go 格式化写入命令。不得以“只增加测试/工具”“临时修改后还原”或扩大任务范围绕过约束。
- Go oracle 仅复用已有只读源码、测试、fixtures、已保存输出或已有二进制；运行已有 Go 工具/测试前，必须确认整个调用链不写上述文件且不需要 failpoint 注入。需要 failpoint 的测试不得直接裸跑来替代验证；无法只读取得必要运行证据时，记录具体缺口并按任务阻塞规则处理，不降低验收标准，不将源码推导冒充运行差分。
- 开始与结束时核对上述文件的 Git 状态及内容，保留用户已有变更；本任务不得产生任何 Go 文件或 Go 模块文件差异。本约束优先于计划、执行技能或验证要求中任何相冲突的写入指令。

目标：将存储选主拆成单一验证故事的小任务，依赖满足后可在独立会话实施。

范围：复用已有 term 的唯一选主实现、显式续租、观察与 reset。

范围外：不实现 etcd 集群成员管理、指标迁移或启动装配。

假设：规划基准 `5d5948052a9ee9e3fa7a09145fe2916a2912c223`；已有 storage/member/id/core/runtime 基线，外部 etcd 仍为过渡后端。新增文件、crate 和测试均为拟建，不代表已经存在。

## 设计决策

- 比较继续聚合与按包拆 crate；选择后者。MetaStore 只下沉到 kv 一次，storage 重导出；领域接口隔离协议。
- 比较按文件整包移植与按行为实现，选择按行为；测试先固定 Go 行为再实现。

## 架构说明

- `storage → endpoint → kv`；`member → election → kv`；keypath 独立，ID 复用 member；协议只进编码适配器。
- 宿主负责 runtime/取消/环境，禁止全局集群 ID、私有 runtime 与第二套 MetaStore。

## 开发策略

- 对行为变更采用失败验证、通过验证、再重构；生产测试置于独立 `*_test.rs` 并显式注册。
- 所有批次全局串行；本计划与其余九个计划共用一条顺序。这样避免根 manifest、Cargo.lock、模块注册、workspace 格式化的写入冲突；没有可并行批次。
- 详细执行顺序、批次、文件占用和任务依赖只保存在编号文件及 `prompt.md`，本文件不记录进度，生成后只读。
- Go 源码和现有测试仅作只读 oracle。只在确认不会写入 Go 且不需要 failpoint 注入后运行已有测试，逐场景记录源码符号、断言、输入与期望；源码推导与实际跨语言运行差分必须分别标明。
- 字节编码任务需要真实 Go 编码输出：仅复用现有 fixtures、已保存输出或经确认只读的已有 Go 工具；禁止新增或修改任何 Go 测试工具。缺少必要输出时记录阻塞。纯源内确定值可记录推导，但不能冒充运行差分。
- root/workspace 新依赖统一精确锁定；已有依赖优先复用。crate 默认 features、无额外 feature，禁止为本计划添加推测开关。
- fixture 复用现有 `scripts/rust-etcd-fixture`：随机 loopback 端口、独立数据目录、同 WAL 重启。共享 helper 的迁移只有 KV 归属整理任务执行，后续调用而不复制。
- Go oracle 仅可复用只读证据或经确认不写入 Go 的已有工具/测试；禁止启停 failpoint 或使用会改写 Go 的 make 测试入口。必要验证依赖这些操作时记录阻塞。跨计划仍须协调源码及 Rust 格式化窗口。
- 文档任务不调用 Cargo。Rust 任务使用编号文件完整槽位契约；有实现变更获得证据后按 `$git-commit` 仅提交本任务变更。
- 任何任务完成依赖本轮证据，新增测试至少命中一例；内存与 etcd 共用断言。不存在编译成功、零测试、mock 调用次数或忽略测试即可验收的路径。
- 主题闭环须覆盖十个子计划全部已准入范围、已记录跨后端/重启/选主/配置差分，并重新盘点基准后的 Go 变化；缺少外部配置依赖时不得关闭来源史诗。
