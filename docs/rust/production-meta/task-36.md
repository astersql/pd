# 生产任务 36 本地长稳驱动

驱动使用独立目录、三个实际存储子进程和固定故障种子。每轮有四个并发客户端，
一次随机目标的双向分区或 leader 进程强制退出。记录每次操作的调用与返回时间，
按唯一标记解析未知提交。检查完一轮后同步完整历史及资源检查点。定期复制压缩命令，
对 SQLite 文件和 RSS 设上限。正常退出等待回收所有子进程，错误保留日志。
[运行器](check_native_history.py)。

校验器复核 24 小时连续窗口、种子、进程回收、完整历史摘要和资源趋势。
短窗口、检查点缺失、历史被篡改或故障覆盖不足都不能通过。
[验收校验器](check_native_soak.py)。

检测器负向核验给短跑回执设置目标窗口 24 小时，但保留真实用时，
验收退出非零并报告 `short monotonic window`。正向的短跑故障历史单独记录。
[故障历史](task-29.md)。
