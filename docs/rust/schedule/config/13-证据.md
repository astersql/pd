## 测试驱动、故障与夹具修复

[red.out](task13/red.out)：指定聚焦命令实际退出 **101**，0 passed / 2 failed，
内存和真实 etcd 均在 `failed persistence must restore the original generation`
断言失败；初版已实现发布和实际保存，缺少回退，没有删掉已有正确实现制造失败。
较早的 lock 更新/fixture 方法名编译错误不作为行为失败。加入 Drop guard 后聚焦
通过；它在保存错误或 future 被取消时恢复原 Arc，先于 writer mutex 释放。

测试 gate 只控制 MetaStore::transact 的 I/O 边界；其余 read/watch/lease/txn 操作
全部转发真实 backend，不模拟配置计算、比较结果或事务成功。注入错误发生在调用
真实 transact 前，保证该反例没有远端写入；生产对真正 Unavailable 不作此保证，
也不重试。真实 NOSPACE 错误另由 Go 进程完成，前序 Rust 真实 etcd 停止/恢复测试
继续随 crate 运行。内存与 EtcdMetaStore 执行同一个 publication/rollback 契约。

首次整 crate 发现两个独立 include 的 etcd fixture 各有私有 NEXT 计数器，却复用
相同 PID，导致 WAL 路径碰撞；[初次失败摘录](task13/validation-initial.out)保留
真实 `failed to create WAL` 及结果。修复为共享批次 12 的单一 fixture 模块，
其 AtomicUsize 统一分配隔离目录。没有忽略、串行化隐藏失败或连接共享实例。
fixture 完整 main.go 及 build 调用链已审查，只构建既有文件，无 failpoint；
`GOARCH=arm64 CGO_ENABLED=0 GOFLAGS=-mod=readonly GOPROXY=off`，产物/WAL
均落在领取槽位。Drop 关闭 stdin 并 wait，必要时 kill/wait，再释放槽位。
