额外边界来自上述Go源码契约，明确不冒称独立Go运行差分：

- 校验先于版本与缺组检查；voter存在检查排序，而健康错误按原输入顺序。
- 输入voter `[3,1,2]`不被改写，持久及返回值为`[1,2,3]`；版本0为管理更新。
- 非过期组可换leader但不可换voter；陈旧版本成功返回原快照，无写入。
  额外先expire使换voter合法，再提交旧token，检查版本与布局不变且backend调用为0，
  从而独立证明版本保护（不依赖voter集合保护）。
- 成功事务清affinity计数并递增版本，保留region计数及create_timestamp。
- busy leader返回内容错误，即便版本陈旧；busy follower可接受。
- nil observation/已available快照跳过；无leader观察错误被吞掉；canonical core
  排除learner，故不存在的learner store99不参与voter校验。
- I/O失败返回错误且内存/版本/持久值不变；观察吞掉I/O错误并保留版本。
