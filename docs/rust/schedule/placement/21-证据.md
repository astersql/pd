## 实现与 oracle

canonical `astersql-pd-schedule-placement` 新 crate，生产公开符号与行为边界见
[rule.rs.md](../../../../pkg/schedule/placement/rule.rs.md)、
[label_constraint.rs.md](../../../../pkg/schedule/placement/label_constraint.rs.md)、

复用 core::StoreInfo 与标签查找，无平行存储或协议类型。
PeerRoleType 与 LabelConstraintOp 使用领域枚举，保留未知 JSON 字符串以供验证；
MetaPeerRole 协议转换不进入领域 crate。Rule 的 clone 深拷贝范围字节和嵌套集合，
不带 runtime group；StoreKey 使用 group/id 的 UTF-8 小写 hex。

只读 Go oracle 为 rule.go、label_constraint.go、rule_test.go TestRuleKeyClone、
label_constraint_test.go TestLabelConstraint/TestLabelConstraints；JSON tag 决定默认、
omitempty、runtime 字段不持久化。源码覆盖：四角色与未知角色、空/未知运算符、
空值等同缺失、nil store false、独占 engine/exclusive/$ 键精确匹配与约束合取；
普通值匹配使用 core 首个大小写折叠键查找。规则 hex 字符串与解码后的 bytes 独立，
本任务不自动验证/解码范围，规则管理器调整属于后续任务。
