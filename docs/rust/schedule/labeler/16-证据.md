## 实现与架构

新增 [keyspace_index.rs](../../../../pkg/schedule/labeler/keyspace_index.rs)、
[模块说明](../../../../pkg/schedule/labeler/keyspace_index.rs.md)，导出
`MAX_KEYSPACE_ID`、`parse_keyspace_rule_id`、`merge_split_keys`、
`KeyspaceRuleIndex::{default,is_empty,add,replace,remove,contains,get_rule,
match_rule,has_split_key,get_split_keys}`。扩展既有 canonical labeler crate，
仅增加既有 canonical codec 依赖，Cargo.lock 只增加该条依赖。

严格检查十进制 ID、24 位上限、index=0、单个 id 标签、value 原文相等、无 TTL/
start_at/expire、精确 raw/txn 范围与不重复 mode。非规范规则进入真实通用
rangelist；Add/Replace 全部预检后更新，Remove 按对象归属。Arc 身份对应 Go
指针身份，不能用相同 ID 的另一对象移除槽。Rust 共享对象不允许原地改写；
调用方以新的已验证快照替换，权威 map 不暴露可变派生引用。

稀疏槽采用 BTreeMap，空间 O(实际槽数)，点查/更新 O(log n)，扫描 O(log n+k)，
复用 codec 编码/解码。查询先计算边界 ID 上下限，不扫描 24 位全集。它没有复制
Go chunk bitmap 的物理布局，也不宣称已达到 Go 百万规则启动 benchmark 的时限。
规范校验使用栈数组和字符串切片；同形状 Replace 只更新 Arc 和已有槽，不创建
新树节点。规范规则更新不重建通用 rangelist；通用分区变动才重建。无变化过期
扫描不会 Arc::make_mut，从而保留槽归属。split keys 合并去重、严格排除端点；
同一通用规则重叠范围仍保留重复出现。没有新增存储、后台任务、指标或 runtime。
