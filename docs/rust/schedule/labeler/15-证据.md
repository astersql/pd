## 实现与边界

新增 [rule_index.rs](../../../../pkg/schedule/labeler/rule_index.rs) 和
[模块说明](../../../../pkg/schedule/labeler/rule_index.rs.md)，公开
`LabelRuleIndex::{new,default,rule,rules,set,delete,get_split_keys,get_range_rules,
min_expire,remove_expired_labels}`。接入现有唯一 labeler crate，Cargo.lock
只增加其 canonical rangelist 依赖；锁生成时产生的无关 pulldown-cmark 升级已排除。

索引拥有规则，用规则 ID 关联真实 rangelist 数据；每次有效修改同步重建派生视图，
相当于 Go 写锁修改后 Unlock 发布。不暴露可变规则引用，防止派生状态失配。
构造相同 ID 后者覆盖，delete 缺失 ID 无副作用。空 end 为无穷；split keys 严格
在起止之间。跨边界为 None，空白单段为 Some(empty)，重叠范围保留规则重复出现。
保留原始有符号 index，不对 map/规则返回次序赋予优先级；区域标签的最大 index
选择和同 index 的未规定胜负由批次 19 承担。当前只实现通用视图，未宣称
canonical keyspace 分区/稀疏快速路径已完成。

过期过滤复用规则模型与调用者传入时间，刷新 min_expire；规则变空仍保留边界，
由后续 GC 决定删除。无持久化、I/O 故障模拟、后台任务或私有 runtime；本任务
不需要新建 MetaStore，真实内存/etcd 存储集成由批次 17 承担。

[oracle.py](task15/oracle.py)复用上一批 Python 的 Bootstrap/HTTP 请求序列：

参数借用现有 segment byte slice，无需注入新 Go 工具。
替换场景通过调试器将已有 low 的 Data 指向 probe 的已验证 Data，并设置 Index=7，
再调用真实 set/buildRanges，验证原对象变更后也不会残留旧边界。这些操作只改
隔离进程内业务对象，不写 Go 源码。
