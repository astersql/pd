## 实现与边界

[模块说明](../../../../server/config/persist_schedule.rs.md)列出公开
`PersistedConfig::{persist,reload}`、`ConfigPersistenceError` 及字段/候选发布语义。
JSON 保持 Config 顶层封装并注入 store。Persist 按 Go 只复制动态分区，其他字段
以 Config 零值保存；Reload 保留宿主静态字段，只在完整解码、GC 并发校验、迁移和
store 派生缓存更新成功后替换活动动态值。默认 scheduler 按类型补齐。

缺失/空字节不发布，非空 null 发布默认配置；旧快照遗漏字段继承 reload 默认值，
region-score-formula-version 保持空。持久化 presence 驱动 legacy rate/default limit
迁移，显式零值优先；废弃 flags 迁移前先校验类型，避免非法输入被吞掉。
配置默认值和 process store limits 由宿主传入/接回，不安装 Go 式全局状态。
并发热发布、回退、TTL 与 SwitchRaftV2 归下一批次；没有后台任务或私有 runtime。
