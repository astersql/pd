### 精确过期边界运行证据

同一已有 Go 二进制的真实 HTTP 规则对象。Delve 在 rules.go:230 暂停，条件为

或 failpoint。Go expire 为 `2100-01-01T01:00:00Z`：

- `label.expireBefore(*expire)`、`rule.expireBefore(*minExpire)` 均 false。
- 两者在 Add(1ns) 后均 true；label 在 Add(-1ns) 后 false。
