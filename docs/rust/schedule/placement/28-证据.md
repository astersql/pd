## 实现及边界

新增 [fit_isolation.rs](../../../../pkg/schedule/placement/fit_isolation.rs) 与
[模块说明](../../../../pkg/schedule/placement/fit_isolation.rs.md)：
`isolation_store_score`、`RegionFit::replace/extra_count/get_rule_fit/region_stores/rules`。
`fit_region` 保留规则与区域已知 store 快照，匹配 Go RuleManager.FitRegion
在内部 fitRegion 后附加的元数据；按区域 peer 次序取 store，排除未知 store 和
无关输入 store。ExtraCount 按已知 store 数减各 RuleFit 的期望 count，可为负数。
get_rule_fit 使用 peer ID，排除 orphan；store 查找使用 store ID，两者不混用。

Replace 先拒绝 nil 目的或未分配的源 store；同规则成员、不同规则但相同角色
直接允许交换，然后才校验标签与替换后的总隔离分。分数相等允许，下降拒绝。
成对评分仅替换源 store，不改写任何快照。复用 core 的 location 比较及既有
label/exclusive-label 逻辑；没有新依赖、proto 领域类型、存储、时钟、I/O、
全局状态或后台任务。本行为无持久化/故障注入契约。
Go fit.go 不读取 IsolationLevel，不能给 fit 添加强制隔离拒绝；该字段由调度调用方
执行。本测试明确证明 isolation_level=zone 时仍可得到低于 zone 的 fit。
