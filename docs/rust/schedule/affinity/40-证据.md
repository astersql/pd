## Oracle 与行为

只读审查 policy.go、metrics.go、manager.go、split.go、affinity_test.go、
policy_test.go、split_test.go 和前序 Rust 接口。Go initialize 先恢复元数据，
失败不启动循环；默认 ticker 10 秒，ctx.Done 退出并 Stop；
changeAvailabilityCheckInterval 仅缩短至100ms，本次用 Tokio paused clock
显式推进10秒，不运行 Go 注入。空组跳过状态与指标更新；变化的 store snapshot
驱动真实 group 可用性转换；expired 不恢复。四个 gauge 使用
`pd_affinity_status`、help `Status of the affinity manager.`、label `type`：
`group-count`、`region-count`、`affinity-region-count`、`split-deny-count`。

固定标签不包含 group/region ID，无高基数标签；每个 child 注册时缓存。

## 覆盖映射

独立文件 affinity_lifecycle_test.rs 经 lib.rs 显式注册，5个匹配测试：

- `affinity_lifecycle_periodic_metrics_and_two_shutdowns`：9秒不检查，10秒真实组
  Available→Expired；四指标全部存在；同 Registry 两次启动/关闭，重复关闭安全。
- `affinity_lifecycle_cancel_waiting_lock_and_registration_failure`：重复注册返回错误，
  无新任务；持有 Manager 锁时父取消仍可 join；零间隔拒绝且无注册泄漏。
- `affinity_lifecycle_split_deny_metric`：真实拒绝一次增量1，Admin放行不计数。
- `affinity_lifecycle_initialization_failure_and_drop_cleanup`：真实内存 MetaStore
  持久化两个组、标签范围重叠，Manager::initialize 失败；不注册、不启动循环；
  Drop 取消后 task-owned registry guard 在任务退出回收。
- `affinity_lifecycle_nonzero_cache_metrics_and_deletion`：真实 RegionInfo/标签/Manager
  缓存匹配，region-count/affinity-region-count 均1，删除缓存后下一周期均0。

无匹配/fit/事务 mock；存储为真实 MemoryStore。新增逻辑不写持久化，初始化复用
canonical 恢复契约；真实 etcd 恢复及事务回归在整 crate/workspace 测试中执行。
