# ADR 生产元数据候选裁决

2026-11-07。**保留本地实验，当前候选未获本轮准入。** OpenRaft 0.9.22 加
rusqlite 0.39.0 和 bundled SQLite 3.51.3，通过隔离虚拟盘的多数派掉电、
快照发布和恢复验证。在对齐 macOS 同步屏障后的同机测量中，写入 p99 和吞吐
仍未达到冻结的 etcd 实验门槛。生产 SLO 留待独立确定。
[耐久性回执](power-evidence.md)、[基线及结果](etcd-baseline.md)。

| 证据 | 裁决 |
| --- | --- |
| 任务3与4，真实磁盘打开和提交边界 | SQLite 建库重开通过。三处子进程中止结果符合同步和外部确认边界 |
| 任务5，快照发布 | 写入、同步、发布、截断四处恢复了相应版本和已应用业务。损坏校验值被拒绝 |
| 任务6与7，追赶和成员配置 | 截断后通过快照追赶，learner 加入并晋升，移除旧节点后继续提交。夹具覆盖一次成功重配置 |
| 任务8与9，磁盘故障和掉电 | 同步报错、空间不足和短写均拒绝确认，并保留先前已确认记录。多数派镜像在弃用原主节点后重新选主，找回已确认键值 |

| 同机写入 | 最差 p99 为613.636 ms，吞吐最低28.536事务/秒。门槛为37.879 ms和73.580事务/秒 |

实验磁盘格式为 SQLite WAL，分开保存日志条目、业务记录和 Raft 元状态。
快照封套为版本1，包含 SHA-256 和 JSON 内容，应用索引、成员与业务数据原子发布。
读由 Raft 线性读屏障保护，成功写等待多数派持久日志及本地应用事务落盘。
节点间 JSON 仅在 loopback 测量夹具使用。生产通信、跨版本兼容与升级窗口待设计。
实验构建和运行平台为 Darwin arm64。仓库默认后端仍按既有外部 etcd 决策运行。

正式复核需在保留同步语义下通过等口径写入门，交付完整 MetaStore 契约、并发
线性历史、原生恢复及长稳回执。主题9的完整准入也需按原计划核验。上述任一
条件缺失时，生产元数据任务11及其依赖保持准入门关闭。
